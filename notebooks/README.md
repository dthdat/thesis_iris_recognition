# Research notebooks

The regular notebooks are source references only. Cell outputs were cleared
before publication so that old measurements cannot be mistaken for current
results. Provide the dataset, split files, and local checkpoints before
executing them.

`iris_baseline.ipynb` is the original protected baseline notebook. It is copied
here without its previous outputs; the original working copy remains outside
this release folder.

`iris_baseline_full_trained.ipynb` is the requested fully executed copy. It
retains historical cell outputs for provenance and teaching review. Treat those
outputs as a record of that notebook run, not as newly reproduced results.
